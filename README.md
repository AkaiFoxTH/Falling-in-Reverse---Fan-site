# Falling-in-Reverse Fan-site

# Sobre o projeto

Este projeto consiste em um site informativo desenvolvido como parte do meu portfólio de desenvolvimento web.

O site apresenta informações sobre a banda Falling in Reverse as informações foram tiradas da wikipedia, incluindo um pedaço de sua história, seus integrantes, seu álbum de estreia e um link para o spotify desse mesmo álbum

Os meus objetivos ao criar esse site são:
1 - Praticar desenvolvimento web com HTML e CSS
2 - Aprimorar a organização e a estruturação de páginas web
3- Desenvolver projetos práticos para compor meu portifólio

Tecnologias utilizadas

HTML 5
CSS3

Próximas melhorias:

Implementar JavaScript, melhorar a responsividade para dispositivos móveis, aprimorar o design e as animações da página

AVISO!!

Este é um projeto independente, desenvolvido para fins educativos e de portfólio. Não possui vínculo oficial com a banda Falling in Reverse. Os direitos das marcas, imagens e demais matérias utilizados pertencem aos seus respectivos títulos
